# Upwork AI Job Post Prompts

## What to Tell Upwork's AI Assistant

When Upwork asks you to describe your job, copy/paste this:

---

## Prompt for Upwork AI:

```
I need to hire multiple social media managers who already own or manage networks of 30-100+ Instagram and TikTok accounts for content reposting campaigns.

Key requirements:
- Must have existing account networks (not building from scratch)
- Need specialists in different niches: music, fitness, fashion, gaming, food, travel, business, sports
- Each account should have 5,000+ real followers
- Real engagement, no bots
- Ability to repost content across entire network within 24-48 hours

This is per-campaign work, not a monthly retainer. I'll send content when I have clients, they repost across their network, and I pay $150-500 per campaign depending on network size.

I'm hiring multiple people (one per niche) for ongoing work with 2-5 campaigns per month per freelancer.

Applicants must provide proof of their network including screenshots, previous campaign results, and engagement rates.
```

---

## If AI Asks Follow-Up Questions:

**"What's your budget?"**
```
$150-500 per project, depending on network size. This is per-campaign work.
```

**"How long is the project?"**
```
Ongoing, more than 6 months. This is recurring work.
```

**"What skills are required?"**
```
Social Media Marketing, Instagram Marketing, TikTok Marketing, Influencer Marketing, Content Distribution
```

**"What experience level?"**
```
Intermediate to Expert
```

**"How many freelancers?"**
```
Multiple freelancers - looking to hire 5-10 people (one specialist per niche)
```

**"What category?"**
```
Social Media Marketing
```

## After AI Generates the Post:

**Review and add:**
1. The detailed job description from UPWORK_JOB_POST.md
2. The 10 screening questions
3. Set to "Multiple freelancers"
4. Add all required skills

---

**Then click "Post Job"**

You'll get applications within 24-48 hours.
